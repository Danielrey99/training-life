# mobile

App móvil del proyecto, construida con **React Native** usando **Expo**.

> 🚧 Carpeta recién creada. Se desarrollará en último lugar, reutilizando lógica del [web](../web) una vez la API del [backend](../backend) esté madura y estable.

Pensada para funcionar en modo **offline-first** (SQLite/WatermelonDB local) y sincronizar con el backend cuando el móvil esté en la misma WiFi que el PC.
