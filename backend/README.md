# backend

API REST del proyecto, construida con **FastAPI** (Python) sobre **PostgreSQL**.

> 🚧 Carpeta recién creada. El código (FastAPI + Dockerfile + conexión a PostgreSQL) se añadirá en el siguiente paso: se construye y prueba primero, de forma aislada (con `/docs`), antes de tocar ningún frontend.

Ningún frontend (web ni móvil) accede directamente a la base de datos: siempre pasan por esta API.
